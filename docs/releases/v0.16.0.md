# Release Notes: v0.16.0

## Overview

This release expands Markdown tooling: `md2html` gains themes, frontmatter, a table of contents and syntax highlighting, and a new `pdf/mkdn2pdf` package converts Markdown to PDF.

## Highlights

- `md2html` renders with themes, YAML frontmatter, TOC generation and syntax highlighting
- New `pdf/mkdn2pdf` package for Markdown to PDF using maroto
- `md2html` CLI reworked with cobra flags (breaking)

## Breaking Changes

The `md2html` command-line tool changed:

- The default output path is now the input name with `.md` replaced by `.html` (previously `<input>.html`, such as `doc.md.html`)
- It prints a conversion summary instead of `DONE`
- Options are now cobra flags

Pass the output path explicitly as the second argument to keep a specific filename.

The exported library API is unchanged.

## Added

### md2html

- `Render()`, `RenderFile()`, `RenderToFile()` and `RenderFileToFile()` take an `Options` value; `DefaultOptions()`, `ArticleOptions()` and `FragmentOptions()` provide presets
- `ParseFrontmatter()` and `HasFrontmatter()` for YAML frontmatter
- Themes `default`, `dark`, `minimal` and `forest`, plus custom CSS tokens, an external CSS file and inline CSS
- `GenerateTOC()` builds the TOC from goldmark heading IDs, so anchors match the rendered HTML
- Syntax highlighting through chroma, with `GetHighlightStyles()` and `GetHighlightCSS()`

```go
result, err := md2html.RenderFile("doc.md", md2html.ArticleOptions())
```

Raw HTML in the Markdown, `CSSInline` and `CSSTokens` pass through unescaped, so render trusted input only. Document metadata and TOC text are HTML-escaped.

### mkdn2pdf

- `MarkdownToPDF()`, `MarkdownToPDFFile()`, `MarkdownBytesToPDF()`, `TableToPDF()` and a `Writer` for building PDFs programmatically
- Supports headings, paragraphs, lists, tables and code blocks
- Zero-valued `Options` fields use defaults; default margins apply when all four margins are zero

## Dependencies

Dependencies were updated. `pdfcpu` is held below v0.16 and v0.16 versions are excluded in `go.mod`, because `pdfcpu` v0.16 adds `context.Context` to its `api` package and `maroto/v2` does not yet support it.
